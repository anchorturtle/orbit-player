# Cloudflare: make anchorturtle.com match GitHub main

## The bug (plain English)

Git pushes **do** update Cloudflare Worker **`orbit-player`** (see `orbit-player.jwals94.workers.dev` — AI videos tab works).

**www.anchorturtle.com** is still an **old deployment** (~20KB `index.html`, no video gallery). The domain is not serving that Worker build.

## What this repo now does on every deploy

1. `npm run build` → writes fresh static files to **`dist/`** (video MP4 excluded; posters + JS included).
2. Wrangler uploads **`dist/`** only (`wrangler.jsonc` → `build.command` + `assets.directory`).

After you push `main`, Cloudflare must run that build. If the build log shows only `wrangler deploy` with **no** `prepare-dist`, the Worker will break — set build command below.

## Cloudflare dashboard (copy these exactly)

### If you use **Workers** (Git → orbit-player)

**Settings → Build**

| Field | Value |
|--------|--------|
| Build command | `npm run build` |
| Deploy command | `npx wrangler deploy` |

(or one line: `npm run build && npx wrangler deploy`)

**Settings → Domains & Routes**

- `www.anchorturtle.com` → this Worker  
- `anchorturtle.com` → this Worker  

Remove the same hostnames from any **old Pages** project.

### If you use **Pages** (Git → orbit-player)

**Settings → Builds**

| Field | Value |
|--------|--------|
| Build command | `npm run build` |
| Build output directory | `dist` |

**Custom domains:** `www.anchorturtle.com`, `anchorturtle.com`

## How you know it worked

Open: `https://www.anchorturtle.com/build-id.json` — should exist and show a recent `builtAt`.

View source on home page — must contain **`AI videos`** and **`video-win`**.

`https://www.anchorturtle.com/js/gallery.js` should be **~29KB**, not ~8KB.

Then: **Caching → Purge everything** once, hard refresh (Ctrl+Shift+R).

## Video file

`jazzpotwax.mp4` is too large for Workers (25 MiB cap). Playback uses GitHub media CDN (`ORBIT_MEDIA_CDN` in `index.html`). Gallery UI and posters deploy normally.
